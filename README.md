I'm an Information Technology student and **Full Stack Developer** with hands-on experience across web, mobile, and backend development.

My professional experience spans React and React Native clients as well as Go and Gin backend services, with work involving booking and payment flows, REST APIs, authentication and authorization, analytics, notifications, localization, and internal Back Office tools.
